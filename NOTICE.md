## Changes made

This copy has been changed from the original. The owner page is the kit's
`dashboard.html` (and `widgets.html`, `assets.html`, `vendor/thinking-orbs.js`),
regenerated by `tools/sync-kit.mjs` with only these substitutions:

- Google Fonts links replaced by local `@font-face` rules (`public/css/kit-fonts.css`)
  and the three.js CDN import replaced by a vendored copy of the same version (r160).
- The page's server address constant set to same-origin, the page and heading
  titled with the shop name and "Blueprint OS", and static asset paths pointed at
  `/static/`.
- The account popover shows the signed-in Blueprint OS user with a Users link and
  Logout, instead of the kit's Claude Code "switch account" control.
- A personal mail address removed from an inbox link, and "open document" opens the
  document in the dashboard's viewer instead of a server-side shell command.

The kit's own server (`server.js`, a zero-dependency Node script) is not used. Its API
is re-implemented for this page in `src/routes/kit-compat-routes.js` on top of this
project's server: per-person logins and roles, the license check, the vault feeds,
the Claude Agent SDK based skill runner and chat engine (instead of spawning
`claude -p` through a shell), artifact visibility scoping and a server-side check of
artifact icons, and the Business Assets folder configured via `src/settings.js`.
Google Calendar and email-triage are not connected in this product (the page shows the
kit's own "not wired" state).

`REDESIGN.md` is carried over from the original kit's reskin-contract
document, updated for this project's own file names and palette. The full
CC BY 4.0 license text is preserved in LICENSE.
